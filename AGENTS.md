# Instrucciones para agentes de código

Las instrucciones de este repo viven en un solo archivo: **[`CLAUDE.md`](./CLAUDE.md)**.

Léelo antes de trabajar. Cubre el modelo multi-tenant, las trampas de Row-Level Security
(que son la forma más fácil de romper el aislamiento sin darse cuenta), los gotchas de
entorno y el alcance aprobado del producto.

Se mantiene un único archivo a propósito: dos copias de las mismas reglas se desincronizan y
terminan contradiciéndose.
